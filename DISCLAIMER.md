# Notă și mențiune – Excel Quest

Excel Quest este un proiect educațional creat pentru a ajuta utilizatorii să învețe concepte de lucru cu foi de calcul, formule, organizarea datelor, dashboard-uri și scenarii de analiză.

## Notă educațională

Conținutul din aplicație este orientativ și are scop de învățare. Lecțiile, provocările, scorurile, proiectele, simulările, certificatele preview și leaderboard-urile demo sunt exemple educaționale.

Acestea nu reprezintă:

- certificare oficială Microsoft;
- curs acreditat;
- evaluare profesională oficială;
- consultanță financiară, contabilă, juridică sau de business;
- garanție de angajare sau promovare profesională.

## Mențiune despre Microsoft Excel

Excel este marcă înregistrată Microsoft. Excel Quest nu este afiliat, sponsorizat, aprobat sau administrat de Microsoft.

Numele Excel este folosit descriptiv pentru a indica tipul de competențe educaționale exersate: formule, tabele, grafice, pivot, data cleaning și analiză de date.

## Mențiune despre datele demo

Toate datele folosite în aplicație sunt fictive sau simulate. Exemple precum vânzări, bugete, note, rapoarte HR, inventar, clienți sau scoruri sunt create pentru exerciții și nu trebuie tratate ca date reale.

Utilizatorii sunt încurajați să nu introducă date personale, financiare sau confidențiale reale în simulatoare.

## Limitări

Aplicația este un proiect front-end demonstrativ. Unele funcționalități sunt simulări locale și pot fi extinse ulterior cu backend, autentificare, baze de date sau exporturi avansate.

Înainte de folosirea într-un context oficial, conținutul, calculele și politicile trebuie verificate și adaptate.
