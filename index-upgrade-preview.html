Lecție-model · Formula IF

Formula IF verifică o condiție și întoarce un rezultat dacă este adevărată, respectiv alt rezultat dacă este falsă.

=IF(B2>=50,"Promovat","De repetat")

Într-un catalog, dacă punctajul din B2 este cel puțin 50, elevul este promovat. Altfel, aplicația afișează mesajul „De repetat”.
